Tropos (Redux frontend) - how to run and check

Needs: Node 20+ and PostgreSQL 14+ running on localhost:5432.

ONE-TIME DATABASE SETUP (once per machine)
  PGPASSWORD=<your postgres password> bash setup.sh
  This creates the database, writes backend/.env with fresh random secrets, runs the migration
  and loads the demo data. (If you prefer to do it by hand: copy backend/.env.example to
  backend/.env, fill the database URLs and the two secrets, then in backend/ run
  npm run db:setup, start the API once, then npm run db:seed-demo and npm run db:seed-history.)

RUN (every time, two terminals)
  Backend:   cd backend && npm install && npm run start:dev      -> http://localhost:4000
  Frontend:  cd frontend-redux && npm install && npm run dev     -> http://localhost:5173
